🎬 Nuvio Account Manager

Universal tool for your Nuvio account: profiles, addons, plugins, cloning, backup and restore, plus the Torrentio size cap as a preset. Everything runs through the official Nuvio Cloud API. tool v2.0.0
🔒 How this page works: it runs entirely in this browser tab and talks only to the official Nuvio API at api.nuvio.tv, the same API Nuvio's own apps use. Your password goes straight from this tab to Nuvio, it is never stored, and the sign-in token lives only in this tab's memory. Close the tab and everything is gone.

👤 Profiles

🧩 Addons

⚠️ Edits are local until you push. Push re-saves this profile's complete addon list (full replace on the server), then pulls it back and verifies the count. Before pushing, the page re-checks the server: if the list changed since you loaded it, the push aborts instead of overwriting.

🔌 Plugins

⚠️ Same rules as addons: local until pushed, complete list on push, verified by a pull afterwards, and the push aborts if the server list moved since you loaded it.

👥 Clone a profile

⚠️ Clone pushes the complete profiles list (existing profiles exactly as pulled, plus the new one, full replace), then pushes the source profile's complete addon and plugin lists into the new profile, then re-pulls everything and verifies the new profile exists with matching counts. Max 6 profiles per account.

💾 Backup & restore

⚠️ Restore overwrites the addon and plugin lists of every profile in the backup file with the file's contents (complete lists, full replace), then verifies each one by pulling it back. The server state as it was right before the restore is saved into Undo first, so a restore can be rolled back per profile and section.
