# The Agent Operator: an anonymized AI practice profile

A single-page profile of how one person uses AI agents and LLMs in depth:
whole-outcome delegation, tokenless background automation, verified
outcomes, standing rules, and a self-scored scorecard.

It is also a template. Everything personal lives in one `PROFILE CONFIG`
block at the top of `index.html`. Copy the page, edit the block, score
yourself with `TEMPLATE.md`, publish anywhere static.

Anonymized by design: the page describes a practice, never a person.
No names, employers, places, handles, or household figures appear in it.

## Files

- `index.html`: the page (the filled example).
- `TEMPLATE.md`: the blank kit: stats, principles, systems, depth ladder,
  scorecard, and an anonymization checklist.
