# Make this page yours

A blank kit for describing how YOU use AI agents and LLMs, with a scorecard.
The filled example lives in `index.html`. Everything personal is in one block
at the top of that file, marked `PROFILE CONFIG`. Edit only that block.

## 4. Your depth

Mark the highest rung you honestly live on, and be able to name the system
that proves it.

- Rung 1, Chat: questions in, answers out.
- Rung 2, Instructions: saved context and memory between sessions.
- Rung 3, Tools: the agent acts in real accounts and apps.
- Rung 4, Schedule: work runs on cadences without being asked.
- Rung 5, Events: code wakes the agent only on real events.
- Rung 6, Custom builds: you build tools for the agent to use.
- Rung 7, Orchestration: agents delegate to agents, budgets managed.
- Rung 8, Operations: the practice itself is audited and improved.

## 6. Anonymization checklist (do not skip)

- [ ] No real name, initials, or handles anywhere, including file names.
- [ ] No employer, school, hometown, or neighborhood.
- [ ] No exact dollar amounts tied to your household.
- [ ] No family members named or described identifiably.
- [ ] Systems described by what they do, never by which account they touch.
- [ ] Screenshots, if any, scrubbed of names, avatars, and balances.
- [ ] Someone who knows you could read it and learn your methods,
      but a stranger could not learn who you are.
