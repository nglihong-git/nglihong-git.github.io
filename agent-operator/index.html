🧑‍🚀 Who this is

This page is deliberately anonymized. No name, no employer, no hometown, no account handles, no dollar figures that point at a real household. The systems are real; the identity is not on the page. That split is itself one of the working rules below.

🧭 The operating principles

These are not aspirations. They are the standing rules the agents actually run under, earned one correction at a time. Every time something went wrong, the fix became a permanent rule, at the broadest scope it applied to.

    🛰️ What runs while nobody is watching

    A small fleet of background systems, each boring on purpose. Code does the watching. Agents wake up only when something real happens, and stay silent when nothing changed.

    🪜 How deep it goes

    Most people stop at the first rung. This practice lives at the bottom of the ladder, and treats each rung as a floor, not a ceiling.

    📊 The scorecard

    Self-scored against the rubric under it. The rule for scoring yourself: a dimension only counts if you can point at a working system or a written rule that proves it. Vibes score zero.

    🏅 The rubric, so you can score yourself

    LevelNameWhat it looks like
    1CuriousAsks chatbots questions. Every task starts and ends inside one chat window.
    2Power userSaved prompts, custom instructions, a few favorite tools. Still does every step by hand.
    3AutomatorScheduled jobs and reminders run unattended. Agents draft, summarize, and fetch on a cadence.
    4Systems builderBuilds custom tools, connectors, and pipelines for the agent to use. Work continues between chats, with logs.
    5OperatorDelegates whole outcomes across life and work. Event-driven automation, verified results, audit trails, standing rules that compound. The human decides; the systems execute.

    📋 Steal this page

    This page is a template wearing a filled-in example. Everything personal lives in one config block at the top of the page source, marked PROFILE CONFIG. To make your own:

    1. Copy index.html and TEMPLATE.md from this folder in the repository.
    2. Edit only the config block: your stats, your rules, your systems, your scores. The layout takes care of itself.
    3. Score yourself honestly against the rubric. If there is no working system or written rule behind a number, lower the number.
    4. Anonymize the way this page does: describe the practice, never the person. Systems yes, identity no.
    5. Publish anywhere static: GitHub Pages, a plain web host, or a single file you send around.

    ⚠️ One caution worth copying too: the deeper agents reach into real life, the more the guardrails matter. Approvals for anything irreversible, secrets in a vault and nowhere else, and verification over trust are what make the rest of this page safe to run.
